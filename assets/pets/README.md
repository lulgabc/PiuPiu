# Pet sprite assets

## Tiny Pets (12 atlases)

- Source: **FREE - Tiny Pets — Animated Pixel Cartoon Pet Pack** by **labitos**
- Source page: https://labitos.itch.io/tiny-pets
- License: free for personal and commercial games, modification allowed.
  The original license forbids reselling or redistributing the assets as a
  standalone asset pack; they are bundled here as part of the PiuPiu game.
- Attribution is not required; this file records the source and terms.
- Each `<pet>.webp` is a 512×256 atlas: 8 columns × 4 rows
  (Idle, Jump, Sleep, Happy), 64×64 frames.
- The game loads only the current pet's atlas, and caches all twelve for offline use.
- Pets: cat, dog, bunny, chick, bear, fox, panda, penguin, frog, dragon, slime, ghost.
