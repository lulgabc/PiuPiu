# PiuPiu · 英语单词爆破

一个把「下落式方块」和「英语单词跟读」结合起来的网页小游戏，也可以切换成「整屏消除」「打彩弹」或「爱读诗」：开局随机铺满单词，读对一个消一个；整屏消除的剩余单词在重力下重新排列，打彩弹则让读对的词被彩弹击中并留下漆弹泼溅，爱读诗把整首诗铺在发光书页上，读对一句点亮一句。

**[在线试玩 →](https://lulgabc.github.io/PiuPiu/)**

**[视觉方向探索 →](https://lulgabc.github.io/PiuPiu/design-lab/)** 三个统一首页、游戏 HUD 和词库页的设计稿；方向 C「街机泡泡」已落地为 2.32.0，并新增「爱读诗」模式。

单词从屏幕顶部随机落下。你对着麦克风正确读出单词，它就会带着不同颜色和动画效果消失；如果一直没读对，单词会落到底部并不断堆积。单词堆到屏幕顶端时，本轮结束。

内置 **500 个核心英语名词与动词**、**20 个主题词库**、**3 套 K-12 阅读词表**（Dolch / Fry / Dale-Chall）、**Paul Nation 的 BNC/COCA 词族表（1k–25k）**，**PHaVE 动词短语表**和 **PHRASE 短语表**，以及一个按 8 个分类组织的**诗集库**。还支持 **自定义词库**：上传文本文章或词表，自动解析成可玩词库，最多保存 12 个。界面支持 **中文 / 法语 / 英语**，可在右上角随时切换。

游戏区背后是一层 **PixiJS 8 环境剧场**：四季 + 古埃及、古希腊、古罗马、太空共 **8 个程序化场景**，完全不干扰玩法。

支持 **PWA 安装**：可以像普通 App 一样添加到手机主屏幕，全屏运行，并在离线时打开已缓存的界面和词库。触屏设备会自动启用更低功耗的渲染档位。

> **环境效果独立预览** → **[pixi-demo.html](https://lulgabc.github.io/PiuPiu/pixi-demo.html)**
> 与游戏内使用同一个引擎；游戏内每局固定一个主题，预览页可手动切换全部 8 个场景。


## 运行

语音识别要求安全上下文，请用本地服务器打开，不要直接双击 `index.html`。

```bash
cd PiuPiu
python3 -m http.server 4173
# 打开 http://localhost:4173
```

或者：

```bash
npm start
```

推荐使用 **Chrome、Edge 或 Safari**，并在浏览器询问时允许麦克风权限。

## 首屏设计

首屏按「街机封面 + 家长抽屉」组织：

- 只保留 **宠物主视觉、四模式、巨大 PLAY、词库/诗集与玩家胶囊**，不再展示大段规则和技术词表。
- 主视觉是一只软果冻宠物，站在发光圆环里；标题「读出来，消掉它」用白到薄荷的渐变，下面只有一行小字。
- **单词雨 / 整屏消除 / 打彩弹 / 爱读诗** 四个模式变成四块迷你街机屏：雨云、方块堆、漆弹和发光书页各自成景，加上编号、状态灯、虚线票根和底部条码；手机 2×2、桌面一排，选中的屏幕会点亮对应颜色并轻轻浮起。
- **词库胶囊**打开「选词库」卡带页；爱读诗模式改为**诗集胶囊**，打开分类诗集页。右上角**齿轮**打开「家长设置」，其中放三套街机色、朗读声音、语音说明和一条简短规则。
- 安装和排行收在 PLAY 下方的小胶囊里；家长设置收进右上角齿轮，当前玩家和最高分只保留一行。
- 开始页直接浮在深色场地上，不显示 HUD、进度点和底部输入栏；进入游戏后自动恢复。
- 所有页面共用深色专注场、霓虹描边、柔和发光和薄荷/珊瑚/柠檬/薰衣草强调色。

## 安装到手机（PWA）

开始按钮下方的工具行提供 **「📲 安装」** 快捷按钮：

- **Android / Chrome / Edge**：点击后弹出浏览器原生安装对话框；也可以在浏览器菜单中选择「安装应用」。
- **iPhone / iPad**：点击后显示 iOS 安装步骤：浏览器工具栏「分享」→「添加到主屏幕」→「添加」。
- 安装后从主屏幕打开会以 **standalone 全屏模式**运行，不显示浏览器地址栏。
- 已安装或从主屏幕打开时，安装按钮会自动隐藏。
- 在较矮的屏幕或手机上，开始面板会自动收紧，保证「开始游戏」和安装按钮无需滚动即可看到。
- 首次打开后 Service Worker 会缓存界面、词库、图标和脚本；之后即使断网也能打开游戏。Chrome 的云端语音识别仍需要网络，离线时可使用键盘输入模式。
- 新版本会通过 `sw.js` 的缓存版本号更新，旧缓存会自动清理；更新后刷新一次即可使用新版本。

安装清单是 `manifest.json`，包含 192 / 512 普通图标和 512 maskable 图标，以及 iOS 使用的 180px Apple Touch Icon。

## 性能与发热（iPad / 触屏）

游戏会在触屏设备、窄屏或 `?lowpower=1` 时自动启用流畅模式，桌面大屏仍保留完整画质：

- **环境画布降分辨率**：PixiJS 渲染分辨率从最高 2× 降到 **1.3×**；iPad 竖屏下像素量约减少一半。
- **环境帧率 30fps**：背景粒子、极光、雪和星海以 30fps 更新；游戏的单词下落逻辑单独限制在 **60fps**，避免 iPad Pro 的 120Hz 屏幕把 DOM 更新也跑到 120fps。
- **粒子数量按比例减少**：花瓣、雪、极光带、星光、尘埃等减少约 40–60%，极光带的降幅更大。
- **遮罩显示时暂停背景**：开始页、暂停页和结束页会停止 Pixi ticker；点「开始游戏 / 继续」后恢复。菜单背景保持最后一帧，不再持续渲染。
- **首次绘制后再准备 WebGL**：低功耗设备先显示菜单，空闲时再创建 WebGL 场景，避免打开页面时被初始化阻塞；如果用户点得很快，会在开始游戏时立即准备。
- **去掉触屏上的实时模糊**：词卡、计分栏、开始遮罩和安装弹层不再使用 `backdrop-filter`，改用更不透明的底色；桌面端仍保留玻璃质感。
- **星空改为合成层动画**：不再逐帧改 `background-position`；触屏上直接关闭这段长动画。
- **其他小动画降级**：触屏上关闭品牌图标、麦克风呼吸和词卡入场模糊动画。
- **GPU 偏好**：流畅模式请求 `low-power`，桌面请求 `high-performance`。

桌面或需要排查体验时，可用 `?lowpower=1` 强制测试流畅模式；在 `?debug=1` 下还可查看 `PiuAmbient.lowPower` 和 `PiuAmbient.running`。

## 街机泡泡视觉系统

全站统一为 **深色专注场 + 霓虹薄荷**：首页、游戏 HUD、词卡、词库卡带、玩家页、排行、家长设置、安装说明、暂停和结算都使用同一套深色面板、胶囊和发光描边。层次只保留三层：**当前任务 / 主要操作 / 次要设置**。首页只有一个巨大的 PLAY，游戏里分数最大、进度最小，次要入口用低对比描边。

三套街机色共用完全相同的布局，只改变深色底和霓虹强调色：

- **薄荷街机**：深海军蓝 + 薄荷绿，默认，最接近设计稿。
- **紫罗兰街机**：紫黑场 + 薰衣草与珊瑚，偏夜间霓虹。
- **柠檬街机**：墨绿黑场 + 柠檬黄与薄荷，清爽、对比更强。

在 **家长设置 → 界面主题** 中切换，立即生效并保存在 `localStorage`。首次打开在 CSS 之前读取主题，避免闪烁；PWA 的 `theme-color` 和启动背景也使用对应的深色底。

界面图标统一为 **内联 SVG sprite**：品牌星、模式、词库分类、按钮、积分星、奖牌和结果提示都使用 `currentColor` 描边，随街机色自动变色，不再依赖系统 emoji 字体。玩家头像和游戏内单词插图仍保留 emoji，因为它们是内容而不是控件图标。

游戏 HUD 里的速度按钮用 **三格速度条 + 当前档位文字** 显示状态：普通是一格柠檬、快速是两格橙色、极速是三格珊瑚；点击后三格、颜色、文字和提示会一起变化。

## 随机宠物

游戏场地里每次都会出现一只 **软果冻宠物小精灵**，从 **35 只**中随机抽取。它们全部来自同一套手绘线稿怪物：

- 毛球、麻薯、布丁、刺刺、星眼、软糖、三眼、角角、雪团、咪咪、嘟噜、天线、奶油、糖豆、泡泡、太阳、小翼、飞飞、啾啾、毛毛、瞪瞪、角宝、幽幽、惊慌、垂耳、高塔、咧嘴、团子、尖牙、小龙、绒绒、叹气、刺猬、蜥蜥、飘飘。
- **玩家不能选择宠物，也没有仓库或队伍上限**；每局开始由系统随机抽 1 只，只避免和上一局完全相同。
- 造型直接来自线稿：自动分色、白色模切边、果冻高光、腮红和独立糖果配色，保留原始轮廓与表情，不是重新画一套近似小怪。
- 每只包含两张资源：完成的果冻贴纸，以及抹平眼睛/嘴巴的底层。Canvas 2D 用底层做**眨眼**和**张嘴**，让原线稿的表情动起来。
- 待机时会呼吸、左右扭动、倾斜和轻微弹跳；开心时跳一下并张嘴，随机还会自己咀嚼；睡着时闭眼。
- 35 只各有独立的名字、三语称呼、糖果色、行为参数和 Web Audio 合成的调皮叫声；叫声由不同波形、音高和短音符组成。
- 行为大脑仍会在 **散步、观察、爬词堆、坐下、梳毛、打盹、蹭玩家、紧张、追流星、受惊、欢呼** 之间按上下文选择。
- 一个 Canvas 只画 1 只宠物，DPR 上限 2，不新增 WebGL 上下文或第三方动画运行时；触屏低功耗、暂停、后台和「减少动态效果」都会降级。
- 支持三套街机色；宠物气泡、影子、HUD 和词卡一起换色。
- 35 只总览见 `design-preview/shots/monster-roster-35-2260.png`；在线图鉴见 `monster-preview/gallery.html`，两只风格原型见 `monster-preview/`。

## 词库与难度

点击开始页的 **词库胶囊** 打开「选择词库」，可以自由选择：

- **综合词库**：500 个核心词，按词长分为初级 / 中级 / 高级；选择「全部」使用完整 500 词。
- **20 个主题词库**：食物、水果、蔬菜、饮品、动物、身体、家庭、服饰、家居、学校、职业、运动、音乐、旅行、交通、自然、天气、科技、情感、地点。
- 每个主题包含 30 个词，分为初级 / 中级 / 高级，每级 10 个词；选择「全部」会混合三个等级。
- **教育词表**：Dolch、Fry、Dale-Chall 三套公开阅读词表，位于词库下拉框的「K-12 阅读词表」分组。
- **BNC/COCA 词族表**：Paul Nation 的 25 个词族列表（1st 1000–25th 1000），位于「词族词表」分组。
- **数字词库**：英语数字 **1–100**，位于「主题词库」分组；可按 1–10、11–20、21–30……91–100 逐段练习，也有 1–50 和 1–100 两个复习范围。说 `twenty one`、输入 `21` 或 `twenty-one` 都能消除 `twenty-one`。
- **短语词表**：**PHaVE 动词短语** 150 个，**PHRASE 短语表** 499 个可玩短语，位于「短语词表」分组。
- 选择短语词表时，卡片会显示完整短语；朗读或输入完整短语即可消除。
- **自定义词库**：在词库页的「我的词库」中上传 `.txt / .md / .csv` 文章或词表，自动解析并出现在「我的词库」分组，最多 12 个、每个最多 600 个词；词条只保存在本机。
- 当前选择会保存到 `localStorage`，刷新或下次打开时保持。
- 开始按钮上方会显示当前词库包含的词条数量。

## 自定义词库

在开始页点击 **词库胶囊 → 我的词库**：

1. 可选填写词库名称；留空时使用文件名。
2. 点击 **选择文本文件**，选择 `.txt`、`.md` 或 `.csv` 文件（最大 2 MB）。
3. 点击 **创建词库**。系统会在本机解析文件，自动去重、清理标点，并创建词库；新词库会立即被选中。
4. 创建完成后可在上方「类别」下拉框的「我的词库」分组中切换；每个词库都可以点右侧 ✕ 删除。

解析规则：

- **词表模式**：每行一个词/短语，或用逗号、分号、竖线、Tab 分隔时，保留原顺序和多词短语（最多 4 个词）；常见的 Markdown 列表符号和标题会被清理。
- **文章模式**：段落式文章会提取英文单词，忽略 `the / and / to` 等常见功能词，并按出现频率排序，优先保留文章中的高频实词。
- 统一转小写，保留撇号、连字符和常见缩写；自动去重，过滤纯数字和无法朗读的符号。
- 每个词库至少需要 4 个不同的英文词；超过 600 个词时只保留前 600 个，并提示已截断。
- 自定义词库按词长分成初级 / 中级 / 高级，可继续使用现有的难度筛选；没有词的等级会自动禁用。
- 删除当前正在使用的词库时，会自动回到「综合词库」；删除其他词库不影响当前选择。

隐私与存储：

- 文件只在浏览器内存中读取，**不会上传到任何服务器**。
- 词库保存在本机 `localStorage`，与玩家积分一样不会跨设备同步。
- 清除浏览器站点数据会同时删除所有自定义词库；浏览器本地存储已满时会提示保存失败。

## K-12 阅读词表

| 词表 | 分级 | 词数 | 说明 |
| --- | --- | --- | --- |
| **Dolch Sight Words** | Pre-K、Kindergarten、Grade 1、Grade 2、Grade 3、Nouns | 315 | 220 个服务词 + 95 个名词，Edward W. Dolch 1936/1948，公共领域 |
| **Fry Sight Words** | First 100 – Tenth 100 | 1000 | Edward B. Fry 的 1000 Instant Words，每 100 词一组，广泛用于北美小学 |
| **Dale-Chall Word List** | 全部词表 | 2940 | New Dale-Chall 可读性公式的熟悉词基准，公开可读性词表 |

- Dolch 和 Fry 选中后会显示单独的**级别下拉框**；Dale-Chall 作为单一词表使用。
- 这些教育词表**按原词表保留功能词**（如 `the / and / a`）和缩写，因为它们是阅读高频词的一部分。
- 单词匹配不区分大小写，并兼容省略撇号的识别结果（`dont` ↔ `don't`、`im` ↔ `I'm`）。
- 数据规范化：`good-bye → goodbye`、`Santa Claus → Santa`；Dale-Chall 中的连字符/缩写词规范为单 token（如 `mr. → mr`）。
- 数据来源均为公开词表：Dolch 为公共领域；Fry 为公开教育词表；Dale-Chall 使用 textstat 的公开 `easy_words.txt` 数据。
- 参考来源：Dolch 官方分组词表（sightwords.com / 公共领域版本）、Edward Fry 1000 Instant Words、[textstat/textstat](https://github.com/textstat/textstat)。

## BNC/COCA 词族表

- **25 个词族列表**：1st 1000、2nd 1000、…、25th 1000
- 共 **25,002 个词族 headword**
- 词族划分采用 Bauer & Nation Level 6（包含常见屈折、派生和前后缀）
- 游戏中每个 headword 代表一个词族；只存 headword，不展开全部词族成员
- 选中后使用单独的级别下拉框选择 1st–25th 列表
- headword 统一为 ASCII 小写；带重音的词会转写（如 `musée → musee`）
- 本数据源包含 25 个频率词族表；官方的专有名词、边缘词、透明复合词和缩略语补充列表未包含在内

**来源与授权：** I.S.P. Nation (2017), *The BNC/COCA Level 6 word family lists*。本项目的 headword 数据来自公开的 BNC/COCA headword lists（Victoria University of Wellington / EAP Foundation 及公开 CSV 转录）。**BNC/COCA 词表版权归 I.S.P. Nation，并非公共领域**；此处仅用于教育和研究用途并保留署名，重新分发或商用前请核对官方条款。

## PHaVE 动词短语与 PHRASE 短语表

### PHaVE List

- **150 个最常用动词短语**，按语料频率排序。
- 游戏内分为三个频率段：**1–50 / 51–100 / 101–150**，每段 50 个。
- 只使用动词短语本身（如 `give up`、`find out`、`look after`），不包含原表 288 条义项释义。
- **来源：** Garnier, M., & Schmitt, N. (2015). *The PHaVE List: A pedagogical list of phrasal verbs and their most frequent meaning senses.* Language Teaching Research, 19(6), 645–666.
- [Norbert Schmitt 词汇资源页](https://www.norbertschmitt.co.uk/vocabulary-resources)（免费下载 PHaVE List、用户手册和频率索引）。

### PHRASE List

- 原表为 **505 条**最常用的非透明多词表达，按 BNC 1K–5K 频率段排列。

- 保留原表的 1K–5K 频率段，各段词条数为 **32 / 84 / 126 / 155 / 102**。

## 表情与儿童化

- 764 个可玩单词配有 emoji；下落时单词卡会**每 1 秒在 emoji 和文字之间轮换**，没有 emoji 的单词保持文字。

- 每次成功会出现本地化鼓励语（⭐ 太棒了 / Bravo / Great!）。
- 界面使用圆润字体、SVG 步骤图标、漂浮品牌动画，结束页改为更温和的「本轮结束」。
- 单词落入底部后会固定显示文字，方便复习。

## 听单词帮助

- 游戏中按 **空格**，或点击 / 触摸游戏区域，系统会大声读出当前**最靠下的下落单词**。
- 被读出的单词会获得金色聚焦描边和喇叭图标，其他单词变暗，聚焦持续约 3 秒。
- 朗读使用系统语音合成（`en-US`，较慢语速，音量 1.0）。
- 家长设置里的 **「朗读声音」** 可选择：自动（推荐）、女声、男声、童声，以及设备里所有英语系统声音；支持试听并记住选择。
- **自动** 会优先挑选设备中的 Premium / Enhanced / Neural / Siri 等高质量英语语音，并排除 Albert、Bells、Zarvox 等搞怪音色，减少机器感。
- **童声** 优先使用系统儿童音色（如 Junior、Eddy）；没有时用高质量女声加轻微音高模拟，不会过度变调。
- **非 iOS** 平台朗读期间麦克风保持监听；系统语音被麦克风收进去的结果会被忽略，读完后立即恢复匹配。
- **iPhone / iPad** 上，Safari 在麦克风识别期间会压低网页播放音量，甚至把声音路由到听筒。为保证帮助发音听得见，iOS 会提前约 150ms 释放麦克风再播放发音，发音结束立即重启识别；其他平台不改变热麦行为。iOS 17+ 还会显式声明 `play-and-record` / `playback` 音频会话，让麦克风和扬声器使用同一条大声的播放路线。
- 如果 iPhone 帮助发音仍然很小，请检查侧边静音键、媒体音量和扬声器遮挡。
- 没有下落单词时会提示稍等；浏览器不支持语音合成时仍会高亮该单词。
- 静音按钮控制游戏音效；帮助语音由系统语音服务播放，可在系统层面调整音量。

## 音效与彩蛋

音效全部由 Web Audio API 实时合成，没有额外音频下载；所有声音经过一个总音量节点和压缩器，避免多个音效同时出现时爆音。触屏设备会自动提高音效增益，桌面保持原音量。静音按钮对所有音效生效。

- **基础音效**：爆破、裂开、飞走、坠落、旋转各有独立的声音；开始、暂停、继续、升级、星光清扫和结束也有专属提示音。
- **卡通音色库**：气泡、弹簧、吱吱、滑哨、卡祖笛、机器人哔哔、火箭升空、恐龙低吼、金币、幽灵、猫叫、狗叫、星尘琶音、神秘音和号角。
- **幸运星单词**：游戏中偶尔会出现带金色边框和 ★ 徽章的下落单词（约 4.5%，且同时最多一个）。读对后额外 +25 分，并触发金币、号角和星星爆发。
- **单词彩蛋**：`robot / rocket / dragon / banana / pizza / ghost / cat / dog / star / magic / rainbow / birthday` 会播放对应的小彩蛋音效和 emoji。
- **随机惊喜**：普通消除时有约 12% 概率出现弹簧、吱吱、滑哨、卡祖笛或气泡音，并有 7 秒冷却，避免过度密集。
- **连击小号角**：连击达到 5 / 10 / 15… 时播放上升号角并撒星星。
- **星星的秘密**：在开始页连续点星星吉祥物 5 次（1.2 秒内），会触发秘密音效和一句隐藏提示。

这些彩蛋只增加声音、动画或额外分数，不改变读词判定的核心规则。

## 语音识别优化

游戏默认使用浏览器的 Web Speech API（Chrome 通常是云端识别）。在当前目标词库很小、需要低延迟的场景下，项目做了这些优化：

- **5 个候选结果（n-best）**：`maxAlternatives = 5`，同时检查所有候选，并按 confidence 选择最可信的目标匹配，而不是只看第一个结果。
- **上下文偏置（Contextual Biasing）**：如果浏览器支持 `SpeechRecognition.phrases`、`SpeechRecognitionPhrase`，**且识别运行在设备端（`processLocally === true`）**，会把当前屏幕目标以 boost 4.0、后续 5 个目标以 boost 2.0 加入提示。Chrome 默认的云端识别会返回 `phrases-not-supported`，因此默认不启用；如果服务不支持，会立即清空偏置并重试，避免“启动—报错—重启”循环。
- **短语容错**：
  - 紧凑形式：`give up` ← `giveup`
  - 常见弱读：`going to` ← `gonna`、`have to` ← `hafta`、`out of` ← `outta`、`there is` ← `there's`
  - 省略冠词：`the extent to which` ← `extent to which`
  - 包含在更长句子中：`give up` ← `give up now`
  - 撇号/同音词/词形变化仍沿用原有容错。
- **更早采用中间结果**：`interimResults = true`，中间结果一旦匹配目标即可消除，不必等待最终结果；单词形式（复数、同音词、短语弱读）会缓存，整屏 35 个目标也只需很小的匹配开销。
- **识别会话中途不重写偏置表**：整屏消除每消一个词都会改变目标集合；现在只标记短语表为 dirty，等下一次识别会话启动时再同步，避免在识别过程中重写 `phrases` 造成停顿。
- **帮助发音时暂停麦克风**：按空格/点击听发音时，所有平台都会先停止识别，避免电脑发音进入识别缓冲区；TTS 结束后重启识别。iOS 还会切回 `playback` 音频会话，保证系统朗读音量清晰。
- **iOS TTS 启动时序**：`speechSynthesis.cancel()` 后短暂等待再 `speak()`，避免 Safari 静默丢弃新的朗读；帮助发音使用独立音量 1.0。
- **iOS 音频会话**：识别开始时声明 `play-and-record`，释放麦克风时切回 `playback`；旧系统或不支持 Audio Session API 的浏览器会自动跳过。
- **TTS 回声保护**：帮助发音期间完全关闭麦克风；TTS 一结束就立即重启识别，不再额外等待保护窗。电脑声音不会进入麦克风，因此不需要牺牲孩子紧接着的第二次发音。
- **提示状态与发音同步**：黄色高亮、喇叭图标和“帮助发音”麦克风文案在 TTS 结束的同一刻清除，不再按固定 3 秒计时器残留 1–2 秒；只有识别到 `onend` 缺失时才由兜底计时器清理。
- **更短的重连空窗**：正常结束约 **90ms** 后重启；连续 no-speech 时退避到 **260ms**，避免空转。
- **启动竞态保护**：遇到 `InvalidStateError` 时最多重试 3 次，避免与浏览器内部状态冲突。
- **延迟观测**：在 `?debug=1` 下可使用 `__PIU__.getSpeechStats()` 查看首个中间结果、匹配延迟的 p50 / p95、候选数、短语偏置是否启用等。

**仍然存在的限制：** Web Speech API 的声学模型、端点和网络延迟由浏览器/服务商控制，网页无法直接调参；`phrases` 属于较新的实验能力，Safari/Firefox 可能不支持。n-best 的低置信候选也有误匹配可能。

如果未来要追求稳定低延迟或离线识别，可考虑浏览器端流式模型（Vosk WASM、sherpa-onnx WASM、Moonshine/Whisper WebGPU）；代价是 20–100MB+ 模型下载、内存/CPU 占用和更复杂的音频前端。以当前游戏的短词/短语目标，保留 Web Speech API + 目标感知匹配通常是延迟与准确率更平衡的方案。

## 玩法

开始页可以在四种游戏方式之间切换，选择会保存在本机：

- **单词雨（默认）**：单词从屏幕顶部随机落下，读对就爆炸，没读对就堆积；堆到危险线结束。
- **整屏消除**：开局从当前词库随机抽词，按 2–3 列铺满游戏区；每读对一个单词就消除，剩余单词作为 Matter.js 刚体在重力下重新排列，全部清空即完成，并按完成数量和用时结算速度奖励。
- **打彩弹**：开局随机抽词，把大小不同的词卡斜着、错落地铺满整个游戏区，而不是排成整齐的墙；每读对一个词，宠物会射出一颗彩弹球，击中词卡的位置炸开一团带飞溅、滴落和卫星色块的彩色油漆，词卡消失但漆迹会留在屏幕上。全部打中后结算速度奖励。
- **爱读诗**：从诗集库里选一首诗，诗句逐行显示在发光的书页上；每读对一行就点亮这一行、留下星火和勾选标记，全部读完后进入「小诗人」结算。可以点任意一行听读，也可以直接打字。

1. 在开始页点击 **词库胶囊** 选择词库和难度，再选玩法并点「开始游戏」，允许麦克风权限；爱读诗模式点击 **诗集胶囊** 选一首诗。
2. 单词雨模式会从顶部随机落词；整屏消除和打彩弹会先铺好一整屏单词；爱读诗会打开选中的诗页。
3. 读对后单词消失或诗句点亮、得分并累积连击；整屏消除中周围卡片会继续受重力下落，打彩弹中彩弹球会飞向目标并留下漆迹，爱读诗中当前行会向下移动。
4. 单词雨中读错或没读，单词会堆在底部；堆到顶部危险线即结束。整屏消除、打彩弹和爱读诗没有危险线，目标是清空整屏或读完整首诗。
5. 没有麦克风、权限被拒绝，或使用 Firefox 时，可以在底部输入框输入单词或整句并按 Enter。

### 爱读诗模式

- 诗集按书中的 8 个分类组织：**家人与朋友、心情、动物与自然、城市与旅行、玩耍、科学与艺术、身体与健康、学习**。
- 每首诗显示标题、作者和逐行正文；当前行有珊瑚/分类色下划线，读对后变成分类色并出现勾选，左侧书脊同步填满。
- 点任意一行会朗读这一行并把它设为当前行；底部输入框可以输入整句作为语音的兜底。
- 每行按「有顺序的词元覆盖率 + 内容词覆盖率」评分，漏掉冠词、复数/所有格差异、少量多说的词都能通过；短句则要求更严格，避免误判。
- 读完一首诗后会记录「已读」书签，并在结算页显示诗名、作者、读对行数、连读和用时。
- 分类决定书页的强调色、顶部书签、背景图标和星火颜色；宠物在书页下沿陪伴，但不会挡住诗句。
- **完整诗集已内置**：153 首诗、8 个分类、2034 行诗句，默认加载，离线可用。
- 诗集数据来自 **A World Full of Poems**（DK, 2020，Sylvia M. Vardell 编选）；诗歌版权归各位诗人所有，已获授权收录。
- 如果需要重新生成诗集数据，运行 `python3 tools/extract-poems.py`（需要 PyMuPDF）。它会写入 `js/poetry.js`，并在 `~/Downloads/PiuPiu-poetry-library.json` 留一份可导入的备份。
- 「诗集 → 导入完整诗集」仍然保留，用来导入其他自定义诗集或备份；导入内容会覆盖内置诗集并保存在本机 localStorage。

### 整屏消除的词块

- **宽度跟单词长度走**：短词是小糖块，长词自动变宽；只有一行词放不下时才换行，不再使用等宽格子。单词太长时会自动缩小字号以保持整词可见。
- **每块颜色不同**：12 个糖果色相随机分配并带轻微抖动，相邻词块不会统一成同一种奶油色；三套街机色分别使用薄荷、紫罗兰和柠檬深色底，卡片描边随强调色一起调整。
- **点词听发音**：点击任意词块会高亮该词、压暗其他词，并用帮助语音朗读；键盘聚焦后按 Enter / 空格也可以听。
- **随机微特效**：词块会周期性随机播放 12 种效果——脉冲、弹跳、摇摆、闪光、柔光、换色、彩虹、扫光、星光、彩纸、表情和光环。减少动态效果时只保留非位移效果。
- 点击只给提示，不会直接消除；仍然要读对或输入正确单词才会消除。

### 打彩弹的词块

- **随机拼贴**：按屏幕面积决定词卡数量，先放大词，再把短词塞进空隙；位置和 ±5° 倾角都随机，不用行列对齐。放置时使用旋转后的包围盒，卡片之间保留安全间距，避免文字互相遮挡或被屏幕边缘裁切。
- **两段命中动画**：读对后单词立即消失，宠物位置射出一颗与词卡同色的彩弹球，沿弧线飞向目标；命中后生成大小差异很大的 SVG 漆弹：小到短促墨点，大到覆盖大半屏幕的夸张泼溅。主漆团由不规则平滑曲线和圆润厚实的漆块构成，墨臂和滴落都使用圆头粗线，末端带圆润漆珠，不会出现尖锐直角；另带紧贴主团的附加漆块、重力滴落、柔和拉长的飞沫和远处细雾。泼溅方向跟随彩弹飞行方向，并配合“发射 / 泼溅”两种合成音效。
- **漆迹常驻在词卡下方**：漆弹层在词卡背后，因此整屏打满后仍然能看清剩余单词；全部打完后结算速度奖励。
- **点词听发音**：与整屏消除一致，点击或键盘聚焦任意词卡会高亮并朗读；帮助发音、语音匹配和键盘输入都沿用现有逻辑。
- 打彩弹没有物理刚体，词卡不会掉落或重排；宠物会**在词卡之间连续跳跃**：每 **2 秒**起跳一次，落到一张词卡的顶边后停留约 1.6 秒，再跳向另一张；词卡被消除时会立刻改跳新目标。跳跃会避开贴近屏幕顶部的卡片，并按高度收小跳跃弧线，避免宠物跳出画面。

### 整屏消除与打彩弹的计分

- 每消除一个单词获得 20 基础分，连击倍率与单词雨相同。
- 整屏消除全部清空后按 `词数 × 3.2 秒` 作为参考用时；打彩弹按 `词数 × 2.6 秒` 作为参考用时。剩余时间越多，速度奖励越高（每提前 1 秒 +8 分）。
- 顶部 HUD 在整屏消除和打彩弹中显示 **剩余词数 + 星光进度**；消除/命中数、用时和速度奖励在结算页集中展示。流星、危险线和下落速度开关会自动隐藏。

## 玩家与积分排行

- **第一次打开**会弹出玩家选择：输入名字、从 **16 个 emoji 头像**中选一个，就能开始累计积分。点玩家行右侧的 ✎ 可以随时修改头像。
- **之后打开**会记住上次的玩家；有多个玩家时会先弹出选择列表，也可以随时点开始页的玩家胶囊切换。
- **总积分**：每读对一个单词，本局得分会立即加到当前玩家的总积分（含连击、高度和幸运星加分），退出或刷新也不会丢。
- **最高分 / 读对词数 / 局数**：每局结束时记录该玩家的最高分，排行榜同时显示累计读对词数。
- **积分排行**：开始页的「🏆 排行」打开独立排行榜，按总积分排序，显示最佳单局和累计读对词数，当前玩家高亮。
- **删除玩家**：玩家列表中每行右侧的 ✕ 可删除该玩家及其积分，需要确认。

> 玩家和积分只保存在**当前设备**的 `localStorage` 中，不会上传，也不会跨设备同步；换浏览器或清除站点数据会重置。排行榜是这台设备上的玩家排行。

## 流星清扫与下落速度

- **每读对 10 个单词**，刚消除的那个单词会变成一颗 ☄️ 流星，以随机角度在游戏区里像台球一样持续反弹，移动速度为原先的 2 倍。
- 每次碰到冻结单词时，只清除**碰到的第一个**，然后立即继续反弹；累计清除 **3 个**或底部**没有剩余冻结单词**时停止。
- 如果底部一开始就没有冻结单词，则不会启动流星；若流星一直没碰到单词，会在约 9 秒后安全停止。
- 流星只清理堆积，不改变读词判定，也不额外加分；被清掉的单词仍保留在结算页的「再练一练」里。
- **游戏画面右上角新增速度按钮**（⚡ 普通 / 快速 / 飞快，1× / 1.6× / 2.3×），玩的时候随时点一下循环切换，立即作用于新出现的单词，并会记住选择。
- 顶部 HUD 收成一条：**得分 / 连击 / 等级或剩余 + 五颗纸星章**；手机上隐藏次要标签，保持一条不换行。
- 流星动画与音效都在游戏循环内驱动，暂停时一起暂停，结束或重开时自动取消。

## 物理堆积

- 已落地的单词会变成 **2D 刚体**，受重力、摩擦、碰撞和旋转影响；卡片会自然叠放、滑落、倾斜甚至倒塌，而不是固定成整齐的刚体方块。
- 单词下落阶段仍由游戏循环控制；落地后才交给物理世界，因此读词判定、语音识别和计分不受影响。
- 底部单词被星光或流星清除后，上方的卡片会失去支撑，在重力下继续下落、碰撞并重新堆积。
- 堆积百分比和危险线使用物理刚体的包围盒计算，倒塌后仍能正确判定游戏结束。
- 物理使用本地内置的 **Matter.js 0.20.0**（MIT），只对已落地卡片启用；开启 sleeping、10 次位置迭代和 8 次速度迭代，在 iPad 上保持稳定和低发热。
- **整屏消除模式复用同一套物理世界**：整屏卡片从开局起就是刚体；消掉一张后，上方卡片失去支撑，在重力下继续下落、碰撞并重新排列。
- **打彩弹不使用物理世界**：词卡是随机拼贴的静态目标，宠物固定在底部；漆弹、卫星色块和飞溅都是轻量 DOM/CSS 动画，不会增加物理计算。
- 物理库加载失败时会自动退回静态堆积，不影响游戏继续运行。

## 计分

- 单词雨：单词越靠近底部被读出，基础分越高（10–20 分）。
- 整屏消除 / 打彩弹：每个单词基础 20 分；全部清空后按参考用时结算速度奖励。
- 连击每增加 1 次，得分倍率增加 0.1，最高 2 倍。
- 单词落地会清空当前连击，并计入「堆积」。
- 最高分和累计积分按玩家保存在浏览器 `localStorage`。

## 单词库

`js/words.js` 提供 500 个核心词；`js/lexicon.js` 提供 20 个主题词库，共 600 个主题词条（572 个跨类别唯一词）；`js/numbers.js` 提供 1–100 的英语数字词，按十位分为 10 段，另有 1–50 和 1–100 复习范围；`js/education.js` 提供 Dolch 315、Fry 1000、Dale-Chall 2940 个教育词条；`js/families.js` 提供 BNC/COCA 25 个词族列表、25,002 个 headword。

`js/emojis.js` 为 766 个词提供 emoji 映射，覆盖核心、主题和教育词表中的大量单词；`js/phrases.js` 提供 PHaVE 150 个动词短语和 PHRASE 499 个短语。

核心词示例：

`apple · kitchen · bicycle · mountain · shoulder · family · accept · build · choose · listen · remember · understand · write`

游戏对同音词做了容错（例如 `sun / son`、`meat / meet`、`flower / flour`），语音识别返回任一拼写都能判定成功。

## 已知限制

- 语音识别使用浏览器的 Web Speech API，识别准确率取决于浏览器、网络、麦克风和口音。
- 帮助朗读使用系统语音合成；音色取决于系统已安装的英语语音。系统未安装儿童音色时，「童声」是高质量女声的轻度音高模拟，听起来不会像真实儿童。
- Chrome 的语音识别通常需要联网；Safari 可能使用系统语音服务。
- 界面语言不会改变目标单词，也不会改变语音识别使用的 `en-US` 语言。
- PWA 离线缓存保证界面和词库可以打开；Chrome 的云端语音识别在断网时不可用，此时可使用键盘输入。
- iOS 的网页播放音量受系统音频会话、侧边静音键和媒体音量共同影响；游戏会在帮助发音时释放麦克风以避开录音会话压低音量，但无法覆盖系统静音设置。
- 流畅模式会降低背景画质以减少发热；如果仍觉得热，可在系统设置中开启「低电量模式」，或暂时关闭麦克风使用键盘输入。
- iPhone / iPad 的安装入口由系统「添加到主屏幕」提供，网页无法直接弹出原生安装框。
- 浏览器不支持 `SpeechRecognition` 时（例如 Firefox），游戏自动使用键盘输入模式。
- 环境场景依赖 WebGL；如果 WebGL 初始化失败，环境层会自动隐藏，不影响单词与游戏逻辑。
- 系统开启「减少动态效果」时不会创建环境画布，只保留静态的游戏背景。
- 短语词表需要朗读或输入完整短语；多词短语的语音识别准确率可能低于单个单词。
- 很长的短语会自动缩小字号以适配卡片宽度，移动端仍可正常显示。
- 麦克风权限被拒绝后，可点击底部麦克风按钮重试，或直接使用输入框。
