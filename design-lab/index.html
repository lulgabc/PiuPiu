PiuPiu · Visual directions

统一视觉，从“先玩”开始。

三个方向都围绕同一个目标：首页只保留一个主操作，游戏里只显示此刻需要的信息， 词库和玩家资料退到第二层。下面每个方向都重做了首页、游戏 HUD 和词库页；这是静态设计稿，游戏本身尚未改动。

A · 果冻游乐场 B · 贴纸故事书 C · 街机泡泡
一屏一个主按钮首页只突出“开始”，其他入口都降为胶囊或图标。
三层信息标题 / 当前任务 / 次要设置，不再把规则、统计、按钮堆在同一层。
游戏 HUD 收成一条分数、进度、暂停和麦克风集中到顶部，输入栏默认收起。
儿童手指优先主要触控目标至少 48px，图标和文字都更大，减少需要读的句子。

游戏HUD 合并成一条胶囊，分数最大、进度最小；底部只保留语音状态。

建议怎么选

A · 果冻游乐场最适合低龄儿童和第一次上手的家长；层级最清楚，组件最少。
B · 贴纸故事书最有品牌个性；适合做成“有性格的绘本 App”，需要更多插画素材。
C · 街机泡泡最有游戏感；适合年龄稍大的孩子，深色页面需要仔细校准对比度。

如果只选一个，推荐 A：最容易让低龄儿童理解，也最适合把玩家、词库、结果页统一成同一套大圆角组件。 也可以混合：A 的首页 + C 的游戏 HUD + B 的词库抽屉。
