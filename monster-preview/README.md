# 宠物小精灵原型（2 / 35）

这是从用户提供的 35 只线稿怪物中先做出的 2 只风格原型，**尚未接入正式游戏**。

## 两只原型

- **麻薯 / Mochi**：草莓果冻、光滑小角、獠牙微笑、会眨眼和开心跳。
- **软糖 / Gummy**：薄荷果冻、大眼大嘴、会眨眼、张嘴和开心跳。

都采用：原始线稿 → 自动分色 → 白色模切边 → 果冻高光/腮红 → Canvas 2D 软体动画。

## 动画能力

- 待机呼吸、左右扭动、倾斜、轻微弹跳
- 随机眨眼；睡着时闭眼并显示 z
- Gummy 会随机张嘴/咀嚼
- 点宠物或按钮触发眨眼、开心跳、睡觉
- 页面同时显示游戏内小尺寸（74px）预览

## 文件

- `index.html` / `style.css` / `monster-pet.js`：独立预览页
- `pets/mochi.webp`、`pets/gummy.webp`：完成脸部的果冻贴纸
- `pets/mochi-base.webp`、`pets/gummy-base.webp`：去掉眼睛/嘴巴的底层，用于眨眼/张嘴动画
- 预览地址：`/monster-preview/`
